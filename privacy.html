Privacy Policy

Last updated: November 3, 2026

Application Purpose

Rclone School Sync is a personal, non-commercial configuration of the open-source Rclone software, used to synchronize files between a local Linux computer and the account owner's Google Drive.

Google Drive Data Access

The application requests Google Drive access to list, read, create, update, and delete files as required for user-authorized synchronization.

Data Storage and Sharing

File synchronization is performed directly between the user's computer and Google Drive using Rclone. The application does not operate an independent server for collecting or storing Google Drive files.

Google Drive data is not sold, used for advertising, or shared with third parties by this application.

Credentials

OAuth authorization tokens are stored locally in the Rclone configuration on the user's computer. They are not published on this website.

Revoking Access

The account owner can revoke application access through their Google Account security settings.
